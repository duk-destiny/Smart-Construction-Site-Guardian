# 01 · 快速开始

> 返回 [README](../README.md) · 下一节 [02 系统架构](02_系统架构.md)

## 环境要求

> 本指南面向**建筑安全领域的多模态智能体**（智护工地）现行版 v2.2：AI 助手 + 影像研判双窗口，React 前端 + FastAPI 单端口。

- Python 3.13（推荐）
- Node.js（仅前端开发/重建 `frontend/dist` 时需要）
- 小模型推理权重（`data/models/*.onnx`）与 BGE Embedding 模型（约 91MB）均随包提供，开箱即用；知识库向量库 `data/kb/chroma/` 已随包提供

## 安装

```bash
# -1.（fresh clone 必须）生成本地配置：真实 config.yaml 不入 git
cp config/config.example.yaml config/config.yaml

# 0. 创建虚拟环境（推荐 Python 3.13）
python -m venv .venv313
.venv313\Scripts\activate          # Windows；Linux/macOS: source .venv313/bin/activate

# 1. 安装依赖（云端 LLM 走 openai SDK，本地兜底走 Ollama）
pip install -r requirements.txt

# 2.（可选）BGE 模型目录缺失时才需联网下载
python scripts/setup_models.py

# 3.（可选）本地 Ollama 拉取 qwen3:8b 作认知层降级兜底（默认走云端 LLM）
#    config.yaml llm.providers 配 api_base/api_key/model，未配置自动落本地；
#    不装 Ollama 则再降级为规则模板
ollama pull qwen3:8b
```

Windows 用户也可直接运行 `./run_app.ps1`：脚本自动创建 `.venv313`、安装依赖并启动应用。

## 启动

| 入口 | 启动 | 地址 | 说明 |
| --- | --- | --- | --- |
| **React 前端（主推）** | `python -m uvicorn api.main:app --host 0.0.0.0 --port 8000` | http://localhost:8000 | 单进程单端口，`frontend/dist` 存在自动托管；Swagger 文档 `/docs`，健康检查 `/healthz`；移动端可用 |
| Streamlit 经典版（回退） | `streamlit run app.py --server.address 0.0.0.0 --server.port 8501` | http://localhost:8501 | 保留至 React 版稳定一个迭代周期后下线 |

admin/safety 登录后默认落地 **AI 助手**（`/chat`），顶栏可切换**暗色/亮色主题**与四套主色（浏览器本地偏好，刷新保持）。责任人账号落地「我的整改单」。

React 前端开发模式（改动前端源码时）：

```bash
cd frontend && npm install && npm run dev   # Vite dev server: http://localhost:5173
# 需放行 CORS：API_DEV_CORS=1 启动 API（或 config.yaml api.dev_cors: true）
# 生产构建：npm run build → frontend/dist 由 FastAPI 静态托管
```

首次启动自动建库并**按用户逐个补种**默认账号（`core/bootstrap.py`，幂等；老演示库升级也会自动补齐责任人而不动既有密码）：

| 账号 | 密码 | 角色 | 权限 |
| --- | --- | --- | --- |
| `admin` | `admin123` | admin | 全权限（含管理端 + 系统自检） |
| `safety` | `demo1234` | safety | 上传/研判/改判/派发，不可进管理端 |
| `lisi` | `demo1234` | responsible | 仅「我的整改单」，提交整改申请验收 |

权限分层由 `services/permission_service.py` 强制校验；种子账号带 `must_change_password=1` 标记，登录后展示改密提醒（`security.force_default_pwd_change: true` 时强制首登改密）。

## 测试


## Docker / CI

```bash
# 构建并启动 api 服务（FastAPI 单进程单容器，端口 8000，静态托管 React 前端）
docker compose up --build -d api

# 容器内运行全量测试
docker compose run --rm api python -m pytest tests -q --tb=short -p no:cacheprovider
```

- `docker-compose.yml` 挂载 `./data:/app/data`，宿主先运行 `python scripts/setup_models.py` 下载 BGE 后容器即可复用；首次启动容器内自动建库并种子默认账号。
- Dockerfile 使用 `python:3.13-slim-bookworm`，apt 源切到 `mirrors.aliyun.com`，避免 `deb.debian.org` 不可用导致构建失败。
- `.github/workflows/ci.yml` 在 push / pull request 时于 Ubuntu 上安装中文字体并运行全量测试（ruff + pytest）。
