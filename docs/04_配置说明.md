# 04 · 配置说明

> 返回 [README](../README.md) · 上一节 [03 功能与页面](03_功能与页面.md) · 下一节 [05 API 接口](05_API接口.md)

全局配置见 `config/config.yaml`（不入 git；fresh clone 从 `config/config.example.yaml` 复制）。敏感值支持 `${ENV_VAR}` / `${ENV_VAR:-默认值}` 环境变量展开，避免明文提交进 git。

## 统一云端通道（v2.2）

LLM / 语音转写（ASR）/ 语音合成（TTS）三条云端通道**共用一对环境变量**：

| 环境变量 | 含义 |
| --- | --- |
| `AI_API_BASE` | OpenAI 兼容端点（含 `/v1`） |
| `AI_API_KEY` | 对应密钥 |

配置方式二选一：写入项目根目录 `.env`（`KEY=VALUE`，gitignore 内，启动自动加载，
已存在的同名环境变量优先）；或直接注入系统环境变量。`config.yaml` 的
`llm.providers[0]` / `asr` / `tts` 均引用 `${AI_API_BASE}` / `${AI_API_KEY}`，
缺任一项该通道按「宁缺毋错」自动降级（本地兜底/能力未配备）。

## 配置段总览

| 段 | 作用 |
| --- | --- |
| `models` | 默认火情模型路径与类别映射；`bge_dir` 本地中文 Embedding 模型路径 |
| `kb` | 规范 PDF 目录、Chroma 集合与持久化路径 |
| `infer` | 置信度/NMS 阈值、抽帧参数、ONNX 线程上限（`intra_op_threads: 0` 自动按物理核/引擎数封顶防抢核） |
| `llm` | 统一 LLM 入口：`providers` 降级链（云端优先，宁缺毋错）+ 本地 Ollama 兜底参数（base_url/model/think/num_predict/temperature/keep_alive） |
| `enhance` | 预填提取非 provider 参数（`total_deadline_sec` 总预算；provider 配置已统一迁入 `llm.providers`） |
| `scenes.*` | 各场景检测头列表 + 知识库集合 + 风险矩阵（`hot_work` / `construction_ppe`） |
| `compliance.severity` | 隐患键 → safe/warning/critical 分级（数据驱动，不改代码可调） |
| `security` | v0.8 账号安全门控（`force_default_pwd_change` 首登强制改密） |
| `upload` | 上传约束：图片 20MB / 视频 200MB / PDF 20MB（服务端魔数校验 + 大小上限） |
| `notify` | 外部推送开关/通道（wecom/dingtalk/generic）/webhook/冷却/演示模式（支持 `${ENV}` 展开） |
| `monitor` | 后台 RTSP 轮询开关/采样间隔/源列表（支持 `demo://` 合成源） |
| `dispatch` | 工单派发规则：数据驱动、自上而下首中即用，scene/zone 通配，assignee 填用户名 |
| `asr` | 语音转写（OpenAI 兼容 /audio/transcriptions）；未配置时前端弹「模型暂未拥有该能力」 |
| `tts` | 语音合成（OpenAI 兼容 /audio/speech，v2.2）；未配置时朗读按钮弹能力提示 |
| `agent` | 认知层上下文与记忆（`memory_enabled`/`memory_sessions`/`recent_turns`，v2.2） |
| `api` | JWT 密钥（`${API_JWT_SECRET}`）/ token 有效期 / 开发模式 CORS |
| `realtime` | 实时 Hub：开关、视频源列表、active_fps/idle_fps、JPEG 质量、告警冷却 |

## 关键段示例

### llm.providers（v2.1 统一 LLM 入口降级链）

```yaml
llm:
  enabled: true
  base_url: http://localhost:11434
  model: qwen3:8b
  providers:
    - name: cloud              # 云端条目必须 api_base+api_key+model 齐全，缺任一整条丢弃
      type: cloud
      api_base: ""             # OpenAI 兼容端点（含 /v1）
      api_key: ${COMPETITION_LLM_KEY}
      model: ""
      timeout_sec: 20
    - name: local              # 云端不可用时的兜底档（复用上方 base_url/model）
      type: local
      model: qwen3:8b
```

列表序即降级序：云端为正常态（success），命中本地及以下均记 degraded。

### scenes（多场景检测头）

```yaml
scenes:
  hot_work:
    conf_thres: 0.35
    yolo_weights:
      - path: data/models/yolov8_fire_smoke_v2.onnx
        class_map: { spark: spark, smoke: smoke, extinguisher: extinguisher }
    kb_collection: kb_hot_work
    risk_matrix: config/rules/hot_work.yaml
  construction_ppe:
    conf_thres: 0.25
    yolo_weights:
      - path: data/models/ppe_yolov8_v3.onnx
        class_map: { helmet: helmet, no_helmet: no_helmet, no_vest: no_vest, vest: vest, person: person }
    kb_collection: kb_ppe
    risk_matrix: config/rules/construction_ppe.yaml
```

场景化后优先读 `scenes.<scene>.yolo_weights`，单模型兜底读 `models.yolo_onnx`；权重文件缺失时该检测头优雅跳过不崩。

### dispatch（工单派发规则）

```yaml
dispatch:
  rules:
    - scene: hot_work
      assignee: lisi
    - scene: construction_ppe
      assignee: lisi
```

自上而下首中即用；scene/zone 均可省略视为通配；无命中时派发面板转手动下拉选择。责任人默认整改时限按风险等级查表：重大 1h / 较大 2h / 一般 24h / 低 168h，派发时可覆盖。

### realtime（实时 Hub）

```yaml
realtime:
  enabled: false             # true 后由 API 进程常驻 Hub 承担视频源推理
  sources: []                # 如 ["rtsp://user:pass@host:554/stream", "demo://"]；留空回退 monitor.sources，再空则 demo:// 兜底
  active_fps: 2              # 有观看者时的推理帧率（每源）
  idle_fps: 1                # 无人观看时的保活帧率（降频省 CPU）
  jpeg_quality: 70
  cooldown_sec: 60
```

启用后 React 实时页经 `/api/ws/realtime` 观看，N 个观看者共享同一路推理（无人观看自动降频保活）；Hub 接管后同进程自动跳过 `monitor.*` 轮询，绝无双路推理。


### agent（认知层上下文与记忆，v2.2）

```yaml
agent:
  memory_enabled: true     # 跨会话记忆开关
  memory_sessions: 2       # 注入规划的最近其他会话数
  recent_turns: 2          # 会话内拼入规划上下文的最近轮数
```

- 会话内：规划输入在摘要外拼入最近 N 轮**原文**（user/assistant 各截 200 字），用于理解"刚才那张单"类指代；
- 跨会话：规划时注入用户最近 K 个**其他会话**的要点（digest ≤120 字/条，标注"仅供理解背景、非本轮指令"，不参与工具参数）；
- 记忆仅为规划提示词的一部分，落 `agent_chat_runs` 证据链可审计，不改变定级与工具白名单。

### 前端本地偏好（无服务端配置）

主题（暗色/亮色 `zhg_mode`、主色预设 `zhg_theme`）存于浏览器 localStorage，按域名隔离、刷新与二次登录保持；纯前端状态，不经任何 API。
