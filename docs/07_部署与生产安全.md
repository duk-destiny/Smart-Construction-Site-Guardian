## 开箱即用

- 小模型推理权重（`data/models/*.onnx`）+ BGE Embedding 模型（model.safetensors，约 91MB）均随包打包，开箱即用；
- PPE 权重版本：仅随包提供后续训练更强的 v3（活跃）/ v4（备用）；v2 因压缩包体积限制不放入，如需可由 `scripts/export_ppe_onnx.py` 重新导出；火情 v2 随包提供；
- 首次启动自动建库 + 种子默认账号（`core/bootstrap.py`）；知识库向量库 `data/kb/chroma/` 已随包提供。仅当 BGE 模型目录缺失时才需运行 `setup_models.py` 联网下载。实时监测态不依赖知识库；
- LLM 认知通道云端优先：`core/chat_client.py` 统一入口，四级降级链（云端 API → 本地 Ollama → 规则模板 → 人工，断路器 + 墙钟总预算）；未配云 key 时走本地 Ollama `qwen3:8b`（keep_alive=30m 常驻，规避 5.2GB 模型反复冷启）；断网/不可用自动降级为模板工单，认知功能不阻断主链路。

## Docker 部署

```bash
docker compose up --build -d api
```

- 当前部署形态为 **api 服务（FastAPI 单进程单容器，端口 8000）**：静态托管 React 前端构建产物，`http://<host>:8000` 即完整系统（Swagger 文档在 `/docs`）；compose 中遗留的 `app`（Streamlit 8501）仅为回退入口，生产无需启动；改动前端后 `npm run build` 重建 `frontend/dist` 即完成前端发版（主题等前端偏好存浏览器 localStorage、按反代域名隔离，无服务端状态）；
- `docker-compose.yml` 挂载 `./data:/app/data`，宿主先运行 `python scripts/setup_models.py` 下载 BGE 后容器即可复用（知识库向量库已随仓库入镜像）；首次启动容器内自动建库并种子默认账号；
- 容器内访问宿主 Ollama 需把 `config.yaml` 的 `llm.base_url` 改为 `http://host.docker.internal:11434`（localhost 配置在容器内不可达）；
- 生产必改：`API_JWT_SECRET` 环境变量（留空则每次重启全体登录态失效）；
- Dockerfile 使用 `python:3.13-slim-bookworm`，apt 源切到 `mirrors.aliyun.com`，避免 `deb.debian.org` 不可用导致构建失败。

## 生产部署建议

以下为演示之外对内网/小规模生产部署的最低安全配置清单：

1. **修改默认账号**：`admin/admin123`、`safety/demo1234`、`lisi/demo1234` 仅供演示。登录后经顶栏「修改密码」更换；管理端「用户治理」可建号 / 重置密码 / 停用账号。生产建议在 `config/config.yaml` 置 `security.force_default_pwd_change: true`，初始密码账号登录后强制改密。
2. **密钥经环境注入**：`notify.webhook_url`、`asr.api_key`、`llm.providers[].api_key`、`api.jwt_secret` 支持 `${ENV_VAR}`（可带默认值 `${VAR:-default}`），避免明文提交进 git。JWT 密钥留空则进程内随机生成——重启后所有登录态失效，仅适合本机开发。
3. **HTTPS 反向代理**：应用自身不带 TLS，前置 nginx/caddy 终结 HTTPS；此时把监听地址收回 `127.0.0.1`，仅由反代对外。Docker 端口映射建议 `"127.0.0.1:8000:8000"`（api 服务）。
4. **数据备份**：SQLite 运行于 WAL 模式，备份需三件同拷：`data/app.db` + `app.db-wal` + `app.db-shm`（或先 `PRAGMA wal_checkpoint(TRUNCATE)`）；另有 `scripts/backup_db.py` 在线备份脚本。
5. **审计留存**：cron 挂 `scripts/audit_maintenance.py --retention-days 365` 定期导出归档 CSV；只有显式追加 `--delete` 才删档，删前自动写 `audit_archive` 凭证并原样重建禁删触发器。
6. **上传限制**：影像上传 200MB / 图片 20MB / 规范 PDF 20MB 上限（`config.upload.*` 可调，服务端魔数校验 + 大小上限双层把关）。
7. **周期任务**：逾期巡检催办由 cron 驱动 `scripts/overdue_scan.py`；风险周报由 cron 驱动 `scripts/weekly_report.py` 周期归档。
8. **实时监测上线检查**：目标机以真实 RTSP 源复跑 `scripts/realtime_acceptance.py`（把脚本内 sources 换成真实地址），确认单推理循环与告警链路在真实源下工作正常。
