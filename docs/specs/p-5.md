## 5. 偏离设计与决策（合理修正）
1. **补全被跳过的基础服务**：Task 4/5 原排在 P0 与 P1 之间，实现中曾被顺延；P5 前补回，否则编排器/UI 无认证与审计支撑（符合依赖方向 ui→services→agents）。
2. **统一 `row_factory=sqlite3.Row`**：DAO 默认返回 tuple，`AuthService` 用列名访问 `row["id"]` 报错；在 `get_conn` 统一设置 Row，向后兼容（Row 仍支持位置索引），一处修复全局受益。
3. **编排器进度含 status**：输出 payload 中每个 Agent 节点改为 `{status, payload}`，UI 卡片才能正确变色（原先仅存 payload 丢失状态）。
4. **视觉回灌规范**：R 先以空 violation_descs 并行启动，V 完成后用真实违规描述补全并轻量二次运行 R（RAG 查询 <1s，符合 C3）。
5. **知识库导入即构建**：`kb_admin.import_pdf` 直接调用 `RagEngine.build`（幂等重建），管理端一次点击完成入库。
