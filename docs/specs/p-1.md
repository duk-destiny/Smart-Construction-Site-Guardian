## 5. 偏离设计与决策（合理修正）
1. **`AgentMessage` 用 dataclass 而非裸 dict**：代码规范 §4 要求"强制封装、禁止裸 dict/list"，dataclass 更类型安全；测试改用属性访问（`.status`）。计划原文用 `out["status"]` 仅为示意。
2. **`AgentBase` 统一包裹计时与异常**：所有 Agent 继承后无需各自 try/except，天然满足"禁止未捕获异常→转 failed"与"记录 cost_ms"（C3 验收）。
3. **`YoloEngine._decode` 独立可单测**：真实权重缺失时，用合成张量验证解码/过滤逻辑，使测试不依赖预置资产（计划 Task 7 允许占位数据）。
4. **`VisionAgent` 支持注入 yolo**：便于测试与编排层复用同一引擎实例，缺权重时自动转 failed 不崩溃。
