- `pytest tests/test_db.py` → **4 passed**（含审计触发器 UPDATE/DELETE 均被拒绝）

## 5. 偏离设计与决策（合理修正，非照抄）
1. **schema 全部 `IF NOT EXISTS`**：原 DB 文档 DDL 未带，实测 `init_db` 二次运行报"表已存在"，改为幂等，符合初始化脚本应可重复执行的常识。
2. **init 审计仅首次写入**：避免每次重跑累积重复 init 日志（仍为 INSERT，不违反仅追加 C4）。
3. **`ConfigLoader` 增加 `get(点路径)`**：计划仅要求 `load`/`get_scene`，实测点路径取值更便利，属合理增强。
4. **向量库构建推迟到 Task 10**：`init_db` 不阻塞等待 RAG 引擎，符合 DB 文档"首次向量库可选"表述。
